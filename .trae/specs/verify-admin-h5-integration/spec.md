# 后台-H5联调闭环验证 Spec

## Why
食堂订餐系统的后台管理端与H5用户端应形成完整闭环：后台创建人员后H5可登录，后台设置菜品/预约时间/调查问卷/通知公告后H5可展示，H5提交意见反馈后后台可查看与回复。需通过实际运行系统逐一验证这些数据链路是否畅通。

## What Changes
- 启动完整系统（backend + admin + frontend）
- 逐项验证以下6条数据链路：
  1. 后台人员管理 → H5手机号登录
  2. 后台菜品管理 → H5菜品浏览/今日菜单
  3. 后台预约时间设置 → H5订餐时间约束
  4. 后台通知公告 → H5公告展示
  5. 后台调查问卷 → H5问卷填写与提交
  6. H5意见反馈 → 后台反馈列表与回复
- 记录验证结果，发现并修复链路断裂问题

## Impact
- Affected specs: 无（纯验证任务，不新增功能）
- Affected code: backend/routes/*, frontend/src/api/*, frontend/src/views/*, admin/src/api/*, admin/src/pages/*

## ADDED Requirements

### Requirement: 人员管理 → H5登录闭环
后台创建的人员应能在H5端通过手机号正常登录。

#### Scenario: 后台人员可在H5登录
- **GIVEN** 后台已创建人员（姓名、手机号、部门等）
- **WHEN** 该人员在H5端使用对应手机号登录
- **THEN** 登录成功，进入H5首页

### Requirement: 菜品管理 → H5菜品展示闭环
后台创建的菜品和每日菜单配置应在H5端正确展示。

#### Scenario: 后台菜品在H5菜品列表展示
- **GIVEN** 后台已创建菜品（名称、价格、分类、图片）
- **WHEN** H5端请求菜品列表
- **THEN** 菜品列表正确展示，包含名称、价格、分类

#### Scenario: 后台每日菜单在H5今日菜单展示
- **GIVEN** 后台已配置当日每日菜单（日期+餐次+菜品）
- **WHEN** H5端请求今日菜单（指定日期和餐次）
- **THEN** 返回正确的当日菜品列表

### Requirement: 预约时间设置 → H5订餐约束闭环
后台设置的预约时间应在H5订餐流程中体现。

#### Scenario: 预约设置数据可被H5获取
- **GIVEN** 后台已配置预约时间设置
- **WHEN** H5端请求预约设置
- **THEN** 返回正确的预约时间配置（餐次、提前天数、起止时间）

### Requirement: 通知公告 → H5展示闭环
后台发布的通知公告应在H5端正确展示。

#### Scenario: 已发布公告在H5展示
- **GIVEN** 后台已创建并发布通知公告
- **WHEN** H5端请求公告列表
- **THEN** 返回已发布（status=1）的公告列表，包含标题、内容、类型

#### Scenario: H5可查看公告详情
- **GIVEN** 存在已发布的公告
- **WHEN** H5端请求某公告详情
- **THEN** 返回该公告完整信息

### Requirement: 调查问卷 → H5填写闭环
后台发布的调查问卷应在H5端展示并可填写提交。

#### Scenario: 已发布问卷在H5展示
- **GIVEN** 后台已发布（status=1）调查问卷
- **WHEN** H5端请求问卷列表
- **THEN** 返回已发布问卷列表

#### Scenario: H5用户可提交问卷
- **GIVEN** H5用户已登录，存在可填写的问卷
- **WHEN** H5端提交问卷答案
- **THEN** 提交成功，后台可查询到答卷数据

### Requirement: 意见反馈 → 后台查看与回复闭环
H5提交的意见反馈应在后台展示并可回复，回复后H5可查看。

#### Scenario: H5提交反馈后后台可见
- **GIVEN** H5用户已登录
- **WHEN** H5端提交意见反馈（类型+内容）
- **THEN** 提交成功，后台反馈列表中出现该条记录

#### Scenario: 后台回复后H5可查看
- **GIVEN** 存在H5用户提交的反馈
- **WHEN** 后台对该反馈进行回复
- **THEN** H5端查看反馈历史时可看到回复内容

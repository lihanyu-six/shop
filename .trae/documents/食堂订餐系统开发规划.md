# 食堂订餐系统 - 分阶段开发规划

## 项目概述

食堂订餐系统包含H5用户端和后台管理端两个部分，严格按照设计稿和原型图开发，确保视觉效果、交互逻辑与原型保持一致。

后台菜单包含：首页、人员管理、意见反馈、调查问卷、预约管理、菜品管理、消费记录、通知公告。

---

## 第一阶段：后台核心模块（首页、人员管理、意见反馈）

### 目标
完成后台管理系统的基础框架和三个核心功能模块

### 后台管理端功能

#### 1. 系统框架与基础功能
- 后台登录页面
- 侧边栏导航菜单
- 顶部导航栏（搜索、通知、个人中心）
- 面包屑导航
- 响应式布局

#### 2. 首页（数据概览）
- **今日统计概览**
  - 今日预定人数
  - 早餐汇总（指定时间：00:00-07:00）
  - 午餐汇总（指定时间：00:00-07:00）
  - 刷新数据按钮
  - 数据同步日期显示

- **订单列表**
  - 搜索功能（姓名输入框）
  - 筛选功能（餐次类型、部门）
  - 导出数据按钮
  - 列表展示：序号、姓名、部门、工号、餐次类型、菜品、菜品备注、取餐码、预定时间
  - 分页功能

#### 3. 人员管理
- **人员列表**
  - 搜索功能（类型名称输入框）
  - 筛选功能（类型下拉选择）
  - 导入按钮
  - 导出按钮
  - 新增人员按钮
  - 列表展示：序号、姓名、部门、工号、手机号码、添加人、添加时间、登录禁用开关、操作栏（编辑、删除）
  - 分页功能

- **人员详情/编辑**
  - 人员信息编辑表单
  - 删除确认弹窗

#### 4. 意见反馈
- **反馈列表**
  - 搜索功能（类型名称输入框）
  - 筛选功能（类型下拉选择）
  - 列表展示：序号、姓名、部门、工号、反馈类型、反馈内容、反馈图片、反馈时间、回复状态、操作栏（回复）
  - 图片预览功能
  - 分页功能

- **反馈回复**
  - 回复弹窗
  - 回复内容输入
  - 回复状态更新

### 技术实现
- 前端框架：Vue 3 + Element Plus + Vite
- 后端框架：Node.js + Koa 2
- 数据库：SQLite
- 状态管理：Pinia
- 路由：Vue Router
- HTTP请求：Axios
- UI组件：Element Plus

## 技术架构

### 前端技术栈
- 后台端：Vue 3 + Element Plus + Vite
- H5端：Vue 3 + Vant UI + Vite
- 状态管理：Pinia
- 路由：Vue Router
- HTTP请求：Axios

### 后端技术栈
- Node.js + Koa 2
- ORM：Sequelize
- 数据库：SQLite（第一、二阶段）→ MySQL（第三阶段后）
- 认证：JWT

### 开发规范
- 遵循原型设计稿1:1还原
- 代码规范统一
- 接口文档完善
- 单元测试覆盖核心业务

## 数据库设计（第一阶段）

### 管理员表 (admin)
- id: 主键
- username: 用户名
- password: 密码（加密）
- name: 姓名
- created_at: 创建时间
- updated_at: 更新时间

### 人员表 (users)
- id: 主键
- name: 姓名
- department: 部门
- employee_no: 工号
- phone: 手机号码
- login_disabled: 登录禁用（0/1）
- created_by: 添加人
- created_at: 添加时间
- updated_at: 更新时间

### 订单表 (orders)
- id: 主键
- user_id: 用户ID
- meal_type: 餐次类型（早餐/午餐/晚餐）
- order_date: 预定日期
- pick_code: 取餐码
- remark: 菜品备注
- status: 订单状态
- created_at: 预定时间
- updated_at: 更新时间

### 订单菜品表 (order_items)
- id: 主键
- order_id: 订单ID
- dish_name: 菜品名称
- quantity: 数量
- remark: 备注

### 意见反馈表 (feedback)
- id: 主键
- user_id: 用户ID
- feedback_type: 反馈类型
- content: 反馈内容
- images: 反馈图片（JSON数组）
- reply_status: 回复状态（0未回复/1已回复）
- reply_content: 回复内容
- reply_time: 回复时间
- created_at: 反馈时间
- updated_at: 更新时间
